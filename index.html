A personal synchronization setup

Your notes, across your own devices.

Obsidian GSync Test connects a local Obsidian vault to a folder in the owner's Google Drive using the open-source GSync community plugin. It is configured for private use across the owner's computers and phones.

Local Obsidian vaults↔Google Drive

What the setup does

It synchronizes notes and attachments, carries file changes between devices, and preserves separate copies when both sides have changed. Deletions can be synchronized through the respective trash locations.

Each device keeps its own Obsidian settings and plugins. On phones, synchronization requires Obsidian to be running; the operating system may pause it in the background.

Why Google access is requested

The plugin uses the Google Drive API to find the configured folder, compare file information, download and upload files, and move deleted files to Drive's trash.

It requests the full Google Drive permission so it can synchronize existing files as well as files it creates. The folder restriction is enforced by the plugin's configuration, not by a Google folder-only permission.

Direct file transfer

Notes and attachments pass between the device and Google's APIs. This setup has no application server that receives or stores notes, client secrets, or refresh tokens. The static sign-in callback page returns Google's one-time authorization response to the GSync plugin on the device.

The privacy policy explains local credential storage, the static host's ordinary request logs, and how to revoke access.

Private use. This website documents an owner-operated synchronization setup. It does not offer public registration, a paid service, or access to anyone's notes. Start authorization inside GSync's settings in Obsidian.
